# M0.1 — Host setup

## Current setup
- Host: Windows + VS Code Remote-SSH -> Pi 5 (key-based, `ssh pi5`)
- Pi is build machine + target for P0–P1
- Linux VM planned before P2 (cross-compile, netboot, Yocto)

## Pi audit
- Kernel: 6.18.50+rpt-rpi-2712, Debian 13 (trixie), aarch64
- 4 cores (Cortex-A76), 7.9 GiB RAM, 2 GiB zram swap
- SD: p1 = /boot/firmware (FAT, 512M), p2 = / rootfs (59G, 46G free)
- serial-getty on ttyAMA10 -> login on 3-pin debug UART

## ELF findings (hello.c)
- ELF64, AArch64, PIE (Type DYN), dynamically linked
- Interpreter /lib/ld-linux-aarch64.so.1 loads libc.so.6 at runtime
- linux-vdso.so.1 = kernel-provided, no file on disk
